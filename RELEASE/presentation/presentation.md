## Основы Синтаксиса Awk

Примеры простых команд Awk:

```
awk '{ print }' file 
awk '{ print $1 }' file 
awk 'NR == 1 { print }' file 
```

- **awk 'pattern { action }' filename**
- **pattern**: условие, при выполнении которого будет срабатывать действие.
- **action**: команда или набор команд, исполняемых для строки, удовлетворяющей условию.

 ![](image/awk4.jpg){#fig:004 width=30%}

## Работа с Полями и Разделителями

По умолчанию awk использует пробелы и табуляцию как разделители полей. Каждый текстовый файл разбивается на поля, которые можно обратиться с помощью переменных:

- $1, $2, …, `$
- n` (первое, второе и т.д. поле).
- NF — общее количество полей в текущей строке.
- FS — переменная для задания разделителя.

![](image/awk5.jpg){#fig:005 width=50%}

Пример:

awk 'BEGIN { FS = "," } { print
$1, $
2 }' file.csv

 
## Условия и Циклы в Awk

**Условия** - Операторы `if`, `else if`, `else` позволяют выполнять разные действия.

**Циклы** - `for`, `while`, `do-while` обеспечивают повторение операций.

**Сравнения** - Операторы `==`, `!=`, `>`, `<`, `>=`, `<=`  сравнивают значения.

- awk '{ if (
- $1 > 100) print $
- 1 }' data.txt

 ![](image/awk6.png){#fig:006 width=40%}

## Ассоциативные Массивы в Awk

Ассоциативные массивы позволяют хранить данные в формате ключ-значение. Это особенно полезно для подсчета уникальных значений.

Пример:

```
{
    count[
 $1]++
 }
 END {
   for (word in count) {
       print word, count[word]
   }
}
```
![](image/awk7.jpg){#fig:007 width=30%}

## Встроенные Функции Awk

Awk предоставляет множество встроенных функций для работы со строками, математикой и временем. Некоторые из них:

- **length(string)**: возвращает длину строки.
- **substr(string, start, length)**: извлекает подстроку.
- **split(string, array, sep)**: разделяет строку на массив с указанным разделителем.

 ![](image/awk8.jpg){#fig:008 width=70%}

## Практические Примеры Использования Awk

**Подсчет строк и полей в текстовом файле:**

- awk 'END { print "Строки:", NR, "Поля:", NF }' file.txt

**Фильтрация данных:**

- awk '$
- 3 > 50' data.txt
 
**Суммирование значений:**

- awk '{ sum +=
- $2 } END { print sum }' file.txt
