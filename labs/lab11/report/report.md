**Контрольные вопросы**

1. Краткая характеристика редактора Emacs

Emacs — это мощный текстовый редактор, известный своей гибкостью и расширяемостью. Он поддерживает различные языки программирования и может быть настроен под конкретные нужды пользователя благодаря встроенному языке программирования Emacs Lisp. Emacs предлагает множество функций, включая автозавершение, подсветку синтаксиса, интеграцию с системами контроля версий, средства работы с буфером и поддержание сессий.

2. Особенности, усложняющие освоение Emacs для новичков

Многофункциональность**: Изобилие функций и команд может показаться подавляющим для новичков.
Клавиатурные сокращения**: Использование комбинаций клавиш, таких как C-x для выполнения команд, требует времени на привыкание.
Стиль управления**: Emacs использует философию "все через клавиатуру", что может быть неинтуитивно для пользователей, привыкших к графическим интерфейсам.
Конфигурация**: Настройка среды через файл .emacs или init.el может быть сложной для тех, кто не знаком с программированием.

3. Описание понятий "буфер" и "окно" в Emacs

Буфер*: *Буфер в Emacs — это область памяти, в которой хранится текст или информация, с которой вы работаете. Каждый файл или документ, открытый в Emacs, загружается в отдельный буфер. Буферы могут быть временными и жить только в рамках текущего сеанса.

Окно*: *Окно в Emacs — это область на экранe, в которой отображается содержимое одного или нескольких буферов. Вы можете разделить окно на несколько частей, чтобы одновременно просматривать разные буферы.

4. Открытие более 10 буферов в одном окне

Да, в одном окне Emacs можно открыть более 10 буферов. Буферы не ограничены числом, и их количество может быть значительно больше, чем 10. Для управления буферами используются различные команды, такие как C-x b, для переключения между ними.

5. Буферы, создаваемые по умолчанию при запуске Emacs

При запуске Emacs создаются следующие буферы по умолчанию:
Messages: для отображения сообщений, уведомлений и вывода команд.
Scratch: вспомогательный буфер, в котором можно делать заметки или тестировать код на Emacs Lisp.

6. Комбинации клавиш для C-c | и C-c C-|

Для последовательного ввода C-c |, нужно нажать:
  Ctrl + c, затем отпустить и нажать Shift + |.

Для C-c C-| нужно нажать:
  Ctrl + c, затем Ctrl + |.

7. Как поделить текущее окно на две части

Чтобы разделить текущее окно на две части, используйте комбинацию клавиш C-x 2. Это создаст новое окно, отображающее тот же буфер, после чего вы можете переключаться между окнами.

8. Файл, хранящий настройки редактора Emacs

Настройки редактора Emacs хранятся в файле .emacs или init.el, который обычно находится в домашней директории пользователя. В этом файле можно писать конфигурации и расширения для настройки среды.

9. Функция <-клавиши и возможность её переназначения

<- (клавиша "Backspace") выполняет функцию удаления символа перед курсором. Эту клавишу можно переназначить в Emacs с помощью команд global-set-key в конфигурации, если необходимо изменить её поведение.

10. Сравнение редакторов vi и emacs

Личное мнение: Emacs представляется более удобным для работы благодаря своей гибкости и возможности настройки. Пользователи могут адаптировать среду под свои нужды с помощью Emacs Lisp. Кроме того, наличие обширной документации и сообществ, а также возможность интеграции различных функций, делает его мощным инструментом для разработчиков.

Vi, в свою очередь, проще и быстрее для освоения базовых операций, но менее гибок в плане настройки, что может быть ограничениям для опытных пользователей.
